# Student Management System

## Project Description

Student Management System is a simple Java-based console application developed to manage basic student records.

## Features

- Add Student
- View Students
- Search Student
- Delete Student
- Exit the application

## Technologies Used

- Java
- Java Collections
- Scanner
- ArrayList
- VS Code

## Concepts Used

- Classes and Objects
- Methods
- ArrayList
- Loops
- Conditional Statements
- Switch Case
- User Input

## How to Run

1. Compile the program using:
   javac StudentManagementSystem.java

2. Run the program using:
   java StudentManagementSystem

## Project Purpose

The purpose of this project is to demonstrate the practical use of Java programming concepts by developing a simple student record management application.
